## Purpose

Adaptive WebMCP contract for personalized, private and portable web accessibility

## Rules

- Use `main` as the canonical branch.
- One agent uses one branch and one worktree.
- Never commit secrets, `.env`, dependencies, databases, generated state, or machine-local files.

- Run relevant validation before completion and report exact blockers.
